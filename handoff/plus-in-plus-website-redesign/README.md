# Plus In Plus — пакет передачи для редизайна сайта

Папка предназначена для переноса в репозиторий сайта
[`ilya-lavrov68/Plus-In-Plus-WebSite`](https://github.com/ilya-lavrov68/Plus-In-Plus-WebSite)
и передачи ИИ-агенту. Она содержит ТЗ, стартовую палитру, два навыка агента и
шаблоны заданий для Hazeglow. Сам сайт и изображения здесь не изменялись и не
генерировались.

## Состав

- `AGENT_BRIEF_RU.md` — основной промпт: аудит, позиционирование, полная карта
  редизайна, реализация и критерии готовности.
- `brand/palette.json` и `brand/palette.css` — фиксированная **базовая палитра**
  по последней правке владельца: акценты `#EEEEEE` и `#FF5F01`, текст на светлых
  и цветных поверхностях `#0E1015`, текст на тёмных `#EEEEEE`, базовые тёмный и
  серый `#110F10` / `#2B292A`. Дополнительные цвета и стили блоков разрешены,
  если они заведены через единую систему токенов и сохраняют заданные пары
  контраста.
- `.agents/skills/plus-in-plus-site-redesign/SKILL.md` — пошаговый навык для
  редизайна всего сайта и удаления старого AI-направления.
- `.agents/skills/hazeglow-dither-ascii/SKILL.md` — навык подготовки
  art-direction, заданий и экспортов Hazeglow в режимах dither / ASCII.
- `prompts/hazeglow-prompts.md` — исходные промпты для hero-фона, bento-артов и
  локальных текстур.

## Как перенести

1. Скопируйте `AGENT_BRIEF_RU.md`, `brand/`, `.agents/skills/` и `prompts/` в
   корень репозитория сайта. Если `.agents/skills/` уже существует, добавьте
   только две новые папки навыков, не перезаписывая остальные.
2. Передайте агенту файл `AGENT_BRIEF_RU.md` и попросите его прочитать оба
   навыка. Пусть агент сначала изучит исходный сайт и его историю, а затем
   выдаст короткий план — не начинайте с генерации изображений.
3. Считайте базовые значения палитры утверждённым фундаментом. Перед
   внедрением сверьте их с актуальным логотипом и материалами Plus In Plus;
   расширять палитру и оформлять блоки можно через централизованные semantic /
   component tokens, не меняя базовые значения без прямого согласования.
4. Создавайте графику через Hazeglow только при наличии инструмента. Если он
   недоступен, агент должен подготовить очередь промптов и временные
   типографические заглушки, а не подделывать результат Hazeglow.
5. Не переносите в новый сайт секреты, локальные `.env`, пользовательские
   данные, большие промежуточные рендеры или чужие изображения без лицензии.

## Уточнение области

В этой задаче подготовлен пакет инструкций и дизайн-токенов для переноса; сайт
из ссылки напрямую не редактировался. Инструкция требует, чтобы следующий
агент проверил реальное содержимое целевого репозитория и не придумывал
неподтверждённые кейсы, цифры, характеристики продукта, адреса загрузок или
контактные данные.
