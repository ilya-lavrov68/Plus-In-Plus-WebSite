# Hazeglow prompt starters

These are art-direction prompts, not claims about a particular Hazeglow interface.
Use the tool's actual supported `dither` or `ASCII` mode and its real export
controls. Keep the owner-approved core colors exactly as specified in
`brand/palette.json`. Any additional shades must first be added as centralized,
approved tokens. Do not generate logos, copy, or fake Line Launcher UI.

## 1. Agency hero — dither field

> Create an abstract editorial artwork for a digital design studio website hero.
> Use Hazeglow's dither mode. Build a confident, restrained composition from
> interlocking modular forms that suggest ideas being shaped into designed
> systems. Keep the primary visual mass on the right half and preserve broad,
> quiet negative space on the left for a real headline and CTA. Use only the
> approved core colors: #110F10, #2B292A, #EEEEEE, #FF5F01 and #0E1015 where
> needed for foreground/surface contrast. Mostly dark neutral tonal structure;
> orange is a small deliberate signal, not a wash over the whole image. Medium-low
> dither density, crisp edges, no extra colors. Wide landscape composition,
> art-directed for a 16:9 desktop hero with a separately reviewed mobile crop.
> No text, letters, numbers, logos, people, fake screenshots, UI, or noisy pattern
> behind the text-safe area.

## 2. Studio / selected-work bento image — ASCII

> Create a compact abstract artwork for one selected-work tile on a design agency
> website. Use Hazeglow's ASCII mode, following the tool's supported character-set
> and density options. Suggest a modular structure through a few large blocks of
> tonal character texture and carefully chosen empty space; make it feel authored
> and editorial, not like a terminal screenshot. Use only the approved core colors
> #110F10, #2B292A, #EEEEEE, #FF5F01 and #0E1015 with correct foreground/background
> roles; use orange as a small signal. Square crop, readable at thumbnail size,
> restrained fine detail. No legible words, fake project UI, code, logos, extra
> colors, thin lines that disappear when reduced, or patterned border.

## 3. Quiet section texture — low-density dither

> Produce a seamless-feeling, very low-contrast dither texture for a secondary
> website section background. Use Hazeglow's dither mode and only the approved
> dark base values #110F10 and #2B292A. The pattern should be sparse, quiet, and
> non-directional so it does not compete with headings or body copy. Wide
> landscape field with no focal subject, no text, logos, borders, high-frequency
> noise, extra colors, or obvious repeated tile seams. This asset is decorative,
> not a standalone illustration; keep the optimized derivative small.

## 4. Line Launcher supporting artwork — ASCII/dither, not a screenshot

> Create a non-literal visual texture for the background of the Line Launcher
> flagship-product module. Use Hazeglow's [ASCII or dither] mode. Evoke the
> contrast between a clean launcher interface and a world of game servers using
> abstract stacked forms, a subtle grid and one portal-like opening. This is
> atmospheric art only: do not draw a believable application UI, buttons,
> settings, logos, game characters, Minecraft assets, or fabricated product
> screenshots. Use only approved core colors #110F10, #2B292A, #EEEEEE and
> #FF5F01; respect the rule that text on orange/colorful fields uses #0E1015 and
> text on dark fields uses #EEEEEE. Keep central text-safe space and make the
> composition crop safely on a narrow phone. Actual product screenshots, if
> available, will be supplied separately and must remain real.

## Prompt and output record

For each actual render, record:

- page/section and final asset path;
- exact prompt and selected Hazeglow mode;
- palette revision and source/master filename;
- master and derivative dimensions, format, and file size;
- desktop/mobile crop review status;
- whether decorative (`alt=""` / CSS background) or meaningful (approved alt);
- approval status and any remaining placeholder.
