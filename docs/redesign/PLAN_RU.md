## 2. Line Launcher: проверенные факты

Источник: `github.com/ilya-lavrov68/Line-Launcher` (README, `branding/line.brand.json`,
`package.json`). Ничего не додумываем — на страницу идёт только это:

- **Что это.** Минималистичный Minecraft-лаунчер для игровых проектов: один
  провайдер — один лаунчер; игрок регистрируется и нажимает «Играть». Адрес
  проекта зашит на этапе сборки, выбирать провайдера и вводить адреса серверов
  не нужно.
- **Стек.** Tauri 2.12, Rust 2021, React 19, TypeScript strict.
- **Платформы.** Windows, macOS, Linux.
- **Возможности (из README).** Мастер первого запуска (язык, фон, движение);
  единый вход в аккаунт проекта; каталог серверов с поиском, фильтрами и
  последним выбором; страница сборки проекта с проверкой целостности, подготовкой
  и откатом релиза; режим Minecraft с запуском в один клик; настройки памяти,
  Java, внешнего вида, окна и данных; гардероб скинов с превью; профиль с 3D-просмотром
  скина; встроенный справочник игрока из шести глав с GIF (по кнопке) и
  reduced-motion-постером; добровольная телеметрия, выключенная по умолчанию.
- **Бренд.** `app_id` — `studio.plusinplus.line-launcher`, издатель — Plus In Plus,
  логотип `branding/assets/logo.svg` (тёплый белый заливки — не перекрашиваем).
- **Статус.** Версия 0.15.4, опубликованных релизов нет. Поэтому на сайте **нет**
  кнопки «Скачать» и обещаний даты релиза — только «оставить заявку» и контакт.
- **Скриншоты.** Реальные: `docs/images/line-{welcome,setup,account,servers,server,server-actions,minecraft,minecraft-actions,settings,privacy,wardrobe,profile,workspace}.png`.
  Копируем в `public/assets/line-launcher/` с указанием источника в манифесте.

## 4. Дизайн-система

Три уровня токенов в `styles/globals.css`:

1. **Primitives** — утверждённые значения владельца, менять нельзя:
   `--pip-neutral #EEEEEE`, `--pip-signal #FF5F01`, `--pip-ink-light #0E1015`,
   `--pip-ink-dark #EEEEEE`, `--pip-surface-dark #110F10`, `--pip-surface-gray #2B292A`.
2. **Semantic** — роли: `--pip-surface`, `--pip-ink`, `--pip-action`,
   `--pip-action-ink`, `--pip-focus`, `--pip-line` (тонкая линия 18% от поверхности).
3. **Component** — существующие роли приложения (`--primary`, `--background`,
   `--card`, `--ring`, `--brand-signal*`) переопределяются из semantic-слоя, чтобы
   компоненты не знали hex-значений.

Проверенные пары контраста (WCAG, sRGB):

| Пара | Контраст | Норма |
|---|---|---|
| `#EEEEEE` на `#110F10` | 16.46:1 | AA/AAA |
| `#EEEEEE` на `#2B292A` | 12.45:1 | AA/AAA |
| `#0E1015` на `#FF5F01` | 6.24:1 | AA |
| `#0E1015` на `#EEEEEE` | 16.40:1 | AA/AAA |

Правила: тени запрещены, focus — `outline` 2px `#FF5F01` с offset 3px,
админка остаётся нейтральным графитом (`.admin-md`), контраст проверяется тестом.

Кнопки: `default` / `primary` / `cta` — оранжевая заливка `#FF5F01` с текстом
`#0E1015`, hover — затемнение до `#E65400`; `outline` / `secondary` / `ghost` —
светлый текст `#EEEEEE` на прозрачном фоне, hover — светлая подложка.

## 5. Hazeglow

`hazeglow@0.6.1` (MIT, zero-deps, React 18/19, WebGL2) — React-компонент
`<Hazeglow config={…} />`, эффекты `dither`, `ascii`, `halftone`, `pixelate`, `glass`.

- **Home hero** — `effect: "dither"`, палитра из трёх токенов (`#110F10`, `#2B292A`,
  `#FF5F01`), `motion: "drift"`, `grain` низкий; текстовая зона слева остаётся чистой.
- **Блок Line Launcher** — `effect: "ascii"`, спокойная плотность.
- **Одна вторичная секция** — `dither` с малой плотностью.
- Компонент уже рисует `aria-hidden` canvas, уважает `prefers-reduced-motion`,
  умеет `onUnsupported` → показываем статичную градиентную подложку.
- CSP не меняется: WebGL внутри своего бандла, внешних скриптов нет.
- Ставим только там, где есть смысл; одинаковую текстуру на все карточки не кладём.

## 9. Проход 40 — композиция без карточек и тихий Hazeglow

Основание — обязательный скилл `project-design-system`
(`.agents/skills/project-design-system/SKILL.md`). Задача экрана, а не
«сделать красиво»: где нужна коробка, где список, где акцент.

| Экран | Было | Стало |
|---|---|---|
| Главная, первый экран | медиа-панель 16:9 в рамке с dither-сценой | кинематографичная полоса из трёх реальных обложек кейсов, растворяется в фоне маской |
| Главная, работы | три одинаковые карточки | крупный кейс + строки с миниатюрами и разделителями |
| Главная, направления | две карточки с постоянным Hazeglow | список из двух строк, свечение только при наведении (`HoverGlow`) |
| Главная, процесс | четыре плашки на серой секции | нумерованный ряд с волосяной линией, без подложек |
| Главная, партнёры | две карточки с логотипами | строка логотипов с вертикальным разделителем и двумя абзацами |
| Главная, бриф | большая стеклянная плашка | типографическая полоса во всю ширину, один акцент |
| Работы | сетка карточек | тот же редакционный ритм: featured + строки |
| Студия | факты, принципы и партнёры в плашках | определения и колонки с линиями |
| Журнал | пустое состояние на Hazeglow | текстовое пустое состояние, только рубрики |
| Line Launcher | светлая сцена, две плашки, CTA-коробка | графитовая сцена с нижним затемнением, колонки, типографический CTA |
| История версий | карточка на каждую версию, цветные маркеры, плашка «последняя» | непрерывная лента с разделителями; логика, поиск, фильтры и якоря не тронуты |

Hazeglow: `effectAmount ≤ 0.15`, `grain ≤ 0.12`, палитра без белого и
оранжевого в фоне, `speed ≤ 0.18`; в контентной зоне страниц с текстом
эффект выключен. Тесты дизайн-системы обновлены под это правило.
