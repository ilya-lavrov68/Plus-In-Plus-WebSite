# Ребрендинг Plus In Plus: сигнальная форма

## 1. Источник и решение пользователя

Основа нового визуального языка — референс, который пользователь конвертировал в SVG и положил в корень репозитория:
`Media posts by Cedrik Stephen (@CedrikStephen) _ Twitter.svg` (736 × 414, трассированное изображение интерфейса соцсети).

Из референса считываются только язык форм и композиция, а не чужой контент, чужие assets или чужая айдентика:

- плоский графитовый фон и крупная типографика;
- один короткий сигнальный фрагмент внутри заголовка;
- крупная сетка и ступенчатая пиксельная мозаика из квадратов;
- полудроп-решётка окружностей;
- острая основная кнопка с заливкой;
- вторичная кнопка-«pill»: прозрачный фон и обводка;
- нейтральные текстовые ссылки навигации и один выделенный пункт-блок.

Два решения пользователя задают иерархию цвета:

1. **Главный цвет бренда — жёлтый.** Periwinkle из референса сохраняется, но работает как вторичный слой.
2. **Геометрия и крупные сетки распространяются на весь публичный сайт, кроме админки.** Админка Payload остаётся в исходном жёлтом оформлении и из редизайна исключена.

Содержание, тексты, структура страниц, CMS, i18n, безопасность и серверная логика остаются собственными решениями Plus In Plus. SVG-референс не копируется в проект и не используется как runtime-изображение.

## 2. Палитра

| Роль | Значение | Токен |
| --- | --- | --- |
| Фон темы | `#181819` | `--background` |
| Несущая поверхность | `#1F1F21` | `--card`, `--popover` |
| Hairline-граница | `#2B2B2E` | `--border`, `--input` |
| Основной текст | `#F4F4F2` | `--foreground` |
| Вторичный текст | `#A6A6AE` | `--muted-foreground` |
| **Главный сигнал** | `#FFFF01` | `--primary`, `--pip-signal`, `--color-brand-signal` |
| Светлый сигнал | `#FFFFA3` | `--pip-signal-strong` |
| Сигнальный wash | `#F7F7CC` | `--pip-signal-wash` |
| Глубокая сигнальная подложка | `#23230D` | `--pip-signal-deep` |
| **Вторичный periwinkle** | `#8F9CFC` | `--pip-violet`, `--color-brand-violet` |
| Светлый periwinkle | `#AFB8FD` | `--pip-violet-strong` |
| Periwinkle wash | `#EAEDFE` | `--pip-violet-wash` |
| Глубокий periwinkle | `#1E2238` | `--pip-violet-deep` |
| Текст на жёлтом | `#12131B` | `--primary-foreground` |

Обе шкалы построены по одной схеме: чистый сигнал → светлый → wash → глубокая подложка. Это позволяет держать одинаковую светлотную логику у двух цветов, не смешивая их роли.

Правило композиции **60/30/10** сохраняется: около 60 % — графитовый фон и основной текст, около 30 % — нейтральные поверхности и границы, не более 10 % — акценты. Жёлтый отвечает за действия и состояния: primary-заливка, активный пункт навигации, focus, редкие сигнальные пиксели. Periwinkle отвечает за масштаб и форму: крупные сетки, орнаменты, hover-волна на primary, направление ИИ.

Жёлтый занимает то же место, что раньше занимал periwinkle, поэтому контраст и иерархия не «прыгают»: тёмный `#12131B` на жёлтом даёт тот же порядок читаемости, что и на periwinkle.

## 3. Геометрия

Правило форм бинарное и намеренно простое:

1. **Острое** — несущие и «основные» поверхности: карточки, панели, диалоги, поля ввода, изображения, обложки, все основные кнопки (`default` / `primary` / `cta`), активный пункт навигации, сетки и мозаики.
2. **Круглое** — только вторичные действия и статусы: `secondary` / `outline` кнопки — pill с прозрачным фоном и обводкой; chips/badges; счётчики; аватары; переключатели.

Реализация:

- радиусы темы `--radius-sm…4xl` обнулены в `styles/globals.css`;
- у кнопок радиус задаётся вариантом: `components/ui/button-variants.ts` даёт `rounded-none` основным и `rounded-full` вторичным;
- вторичные кнопки — `bg-transparent` + `border` без заливки в покое.

## 4. Геометрия страниц

`components/site/brand-geometry.tsx` содержит детерминированные примитивы:

- `PixelMosaic` — ступенчатая мозаика квадратов, плотность набирается к заданному углу (`corner`);
- `DotLattice` — полудроп-решётка окружностей;
- `GridField` — крупная техническая сетка с детерминированно залитыми клетками или только линиями (`linesOnly`);
- `SignalBlocks` — короткая линейка острых блоков.

У примитивов есть `tone`: `violet` (по умолчанию для крупных сеток), `signal` (жёлтый) и `mixed` (пурпур с редкими жёлтыми вкраплениями). Всё строится math-хешем без `Math.random`, поэтому SSR и client render совпадают, а тесты проверяют структуру. Элементы всегда `aria-hidden` и `pointer-events-none`.

`components/site/page-geometry.tsx` распределяет геометрию по маршрутам так, чтобы композиции **различались** — это прямое требование пользователя: не накладывать один и тот же декоративный блок на каждую страницу.

| Маршрут | Композиция | Характер |
| --- | --- | --- |
| `/services` | `ServicesGridBand` | широкая смешанная сетка под шапкой, затухающая маской |
| `/shop` | `ShopSideGrid` | узкое вертикальное поле справа, без заливок под карточками |
| `/blog` | `BlogLatticeField` | решётка окружностей в правом верхнем углу шапки |
| `/contact` | `ContactGridColumn` | вертикальная колонка слева от формы + сигнальная линейка |
| `/login`, `/signup`, `/register` | `AuthMosaicField` | жёлтая мозаика в нижнем левом углу |
| `/privacy`, `/terms` | `LegalLineBand` | только линии, текст остаётся главным |
| `/ai`, `/ai/lumi`, `/ai/kairo` | `AiGridBand` | плотная крупная сетка с жёлтыми вкраплениями |
| Главная (`Story`) | `StorySignalRule` | короткая линейка вместо декоративной полосы |

Hero использует `GridField` на всю ширину плюс `PixelMosaic` и `DotLattice` по нижним углам. Крупные внешние отступы сохранены: сетка не подлезает под текст, информация не зажата.

## 5. Hero и навигация

- Hero: крупная сетка, eyebrow с квадратным маркером, двухстрочный заголовок (`muted` + `foreground` + короткий `text-primary` на жёлтом), описание, острая основная кнопка, pill-вторичная, монохромная подпись; снизу по углам — мозаика и решётка.
- Шапка: нижняя hairline-граница, нейтральные ссылки, активный пункт — прямоугольный блок с жёлтой заливкой и тёмным текстом, CTA — pill-обводка, вход — острая кнопка.
- Мобильная нижняя панель сохраняет messenger-like структуру; активная иконка — острая жёлтая плашка.
- Primary-кнопка в покое жёлтая; при precise-pointer hover из точки входа курсора растёт пурпурная волна через общий delegated controller `.pip-cursor-fill`.

## 7. Изменённые assets

- `public/assets/logos/lnpip.svg`, `npip.svg` — жёлтые `#FFFF01` сигнальные элементы и белые нейтрали (исходная жёлтая версия);
- `public/assets/pixels/direction-*.png` — пересобраны `npm run sprites:directions` из палитры `scripts/generate-direction-sprites.cjs`, где `accent` снова `#FFFF01`;
- `public/assets/agents/*` — предрендеренные shader-циклы и poster-WebP возвращены в жёлтую рампу: единственный spark остаётся жёлтым сигналом, геометрия и длительности не менялись;
- `payload/components/admin-brand.tsx`, `app/(payload)/custom.scss` — **не входят в редизайн**: админка осталась в исходном состоянии с акцентом `#ffff01` и своими нейтральными поверхностями.

## 8. Проверка

- `npm test` включает контрактные тесты бренда: `tests/brand-geometry.test.cjs`, `tests/cursor-fill.test.cjs`, `tests/site-components.test.cjs`, `tests/admin-animated-icons.test.cjs`, `tests/direction-sprites.test.cjs`;
- `npx tsc --noEmit` и `npx eslint .` — без ошибок;
- серверный рендер: `/ru`, `/ru/services`, `/ru/ai`, `/ru/ai/lumi`, `/ru/ai/kairo`, `/ru/blog`, `/ru/contact`, `/ru/login`, `/ru/signup`, `/ru/privacy`, `/ru/terms`, `/ru/shop`, `/ru/cart` — ожидаемые `200`/`307` для гостя.

Ограничение: в окружении сборки нет браузера (Chromium не запускается без системных `libnspr4/libnss3`), поэтому реальный browser review, скриншоты и проверка hover-заливки указателем выполняются вне песочницы: desktop/mobile, клавиатурный focus, reduced motion, RU/EN, длинные тексты и touch-устройства.
