# Дизайн-план Plus In Plus

Документ фиксирует направление редизайна публичного сайта: что берём из референса, какие правила
нельзя нарушать, как устроены «воздух», сетки и движение, и как разложены страницы. Формат опирается
на `DESIGN.md` из OpenDesign (разделы «тема и атмосфера → палитра → типографика → сетка → компоненты →
движение → приёмка») и на их принцип работы `brief → direction → design system → artifact`: сначала
система, потом сборка экранов, а не набор случайных блоков.

Админка Payload в этот план не входит и остаётся в исходном состоянии.

---

## 1. Источник формы: референс

Референс — кадр 733×413 с тёмным холстом и одной центральной мыслью. Из него берём композицию и язык
форм, но не контент, не логотипы и не чужие ассеты:

| Элемент кадра | Что берём | Что не берём |
| --- | --- | --- |
| Редкая сетка точек по всему холсту | текстура фона hero, `opacity` 40–60 % | чужую плотность и размер точки как константу |
| Крупная двухстрочная типографика по центру | масштаб и вес заголовка | конкретную гарнитуру и текст |
| Один выделенный токен («99 %») в плашке | ровно одно подсвеченное слово на экран, `.pip-mark` | заливку чужим цветом |
| Микро-подпись в 2 строки | максимально короткое описание под заголовком | мелкий нечитаемый кегль |
| Две кнопки разной формы | primary — жёлтая острая; secondary — pill с обводкой | чужие подписи и pill-форму у primary |
| Пиксельная волна в левом нижнем углу | `PixelMosaic`: сплошная масса квадратов с плавным ступенчатым гребнем | чужой цвет и случайную россыпь клеток |
| Полудроп-решётка окружностей справа снизу | `DotLattice` с той же волновой границей — второй контраст «круглое рядом с острым» | пересечение с текстом и кнопками |
| Плавающая навигация-пилюли | идею «навигация как отдельный слой над холстом» | чужой набор пунктов |

Ключевой вывод из сравнения: референс держится на **пустоте и одном акценте**. Всё, что в текущей
версии делает экран плотнее (сетка под текстом, второй и третий акцент, повтор одинаковых CTA-пар),
считается ошибкой и убирается.

## 2. Чему научили два источника

**`motion` / `motion-ai`.** Пакет `motion` уже в проекте (`^14.2.0`) и используется как `motion/react`;
CLI `npx motion-ai` интерактивный и в сборочной среде без терминала не запускается, поэтому его
рекомендации применяются вручную: движение задаётся декларативно, длительности 120–260 мс, кривые без
упругих отскоков, всё уважает `prefers-reduced-motion`, а бесконечные циклы допустимы только там, где
они несут смысл (shader-видео ИИ-агентов). Декоративные hover-эффекты делаются на CSS, без JS-слушателей.

**OpenDesign.** Берём три вещи:
1. дизайн-система описывается отдельным документом с обязательными разделами (палитра, типографика,
   сетка, компоненты) и этот документ — источник истины для страниц;
2. «функциональные скиллы» и «шаблоны» разделены: у нас шаблон — это блок (`Hero`, `CTA`), а не копия
   целой страницы; страницы собираются разными комбинациями, а не одной матрицей;
3. в их motion-шаблоне прямо зафиксировано: тонкая геометрия (штрихи 0.5–1 px), точечная текстура
   22–32 px, анимация — inline CSS, а не рантайм-движок. Это совпадает с нашим запретом на тени и
   тяжёлые эффекты.

## 3. Цвет: жёлтый сейчас, пурпур — в резерве

| Роль | Токен | Значение | Использование сейчас |
| --- | --- | --- | --- |
| Главный сигнал | `--pip-signal` | `#FFFF01` | primary-заливка, активный пункт, focus, подсветка слова |
| Светлый сигнал | `--pip-signal-strong` | `#FFFFA3` | пиксельная заливка кнопки при hover |
| Сигнальный wash | `--pip-signal-wash` | `#F7F7CC` | редкие светлые вкрапления орнамента |
| Глубокая подложка | `--pip-signal-deep` | `#23230D` | тёмные клетки мозаики, глубина без теней |
| Вторичный periwinkle | `--pip-violet` | `#8F9CFC` | **сохранён в токенах, в UI не используется** |
| Его шкала | `--pip-violet-strong/wash/deep` | `#AFB8FD` / `#EAEDFE` / `#1E2238` | **в резерве** |
| Фон / текст | `--background` / `--foreground` | `#181819` / `#F4F4F2` | основа |
| Границы | `--border` | `#2B2B2E` | hairline-структура |

Правила:

- пурпур не появляется ни в одном публичном компоненте: ни в орнаментах, ни в hover, ни в чипах;
- шкалы `--pip-violet*` и утилита `.pip-chip--violet` остаются в CSS как резерв на будущее;
- композиция 60/30/10: 60 % — фон и основной текст, 30 % — нейтральные поверхности и границы, ≤10 % — жёлтый;
- теней нет вообще: глубина только фоном, границей и отступами.

## 4. Типографика и «воздух»

- Заголовок hero: `clamp(2.5rem, 7vw, 5.5rem)`, вес 700, интерлиньяж 0.98, трекинг −0.035em.
- Заголовки секций: 30–48 px, вес 600, трекинг −0.02em.
- Основной текст: 15–17 px, интерлиньяж 1.6–1.7, ширина строки 52–68 символов.
- Микро-подпись и eyebrow: 11–12 px, uppercase, трекинг 0.18–0.2em, цвет `--muted-foreground`.
- Один акцентный токен на экран: `.pip-mark` (подсветка слова в заголовке) либо активный пункт меню,
  но не одновременно в двух местах одного вьюпорта.

Вертикальный ритм — кратно 8 px. Минимальные просветы, ниже которых считается «зажато»:

| Между чем | Минимум |
| --- | --- |
| hero-заголовок → описание | 32 px |
| описание → кнопки | 36 px |
| кнопки → нижний декор | 96 px (мобильный — 64 px) |
| секции на странице | 96 px мобильный / 128 px планшет / 160 px десктоп |
| заголовок секции → её контент | 40 px |
| текст → край декоративной сетки | 24 px |

## 5. Сетка и геометрия

- Контейнер: 1200 px, боковые отступы 24/32/48 px.
- Крупная техническая сетка `.pip-tech-grid` — 96 px, `--bold` — 144 px, opacity линий 0.05/0.09.
- Точечное поле `.pip-dot-field` — 26 px, только hero главной.
- Декор живёт в собственной зоне (`absolute`, маска, `pointer-events-none`, `aria-hidden`), контент
  всегда выше (`relative z-10`). Один декоративный слой на экран.
- Волны строятся по профилю `waveHeight(u, seed)`: затухающий к дальней стороне конверт плюс две
  низкочастотные синусоиды. Гребень никогда не разрывает массу на отдельные «группы» — силуэт
  остаётся единой волной, а редкие одиночные пиксели над ним работают как брызги.
- На странице максимум два орнамента, и они не повторяют набор с другой страницы.

## 6. Движение

- **Кнопки.** В покое — жёлтая заливка. При наведении/фокусе — быстрая пиксельная заливка: крупные
  клетки (24 px тайл, 12 px клетка) проявляются за 220 мс шагами `steps(6, end)` слева направо.
  Волна из точки курсора удалена вместе с JS-контроллером; пурпур в анимации не участвует.
- **Появление.** `data-reveal` со сдвигом 8–12 px и задержкой 0/60/90/140 мс, длительность 300–400 мс.
- **Скролл-сценарии.** Только там, где несут смысл: линия истории студии, появление карточек блога.
- **Видео.** Shader-циклы ИИ-агентов остаются единственным бесконечным движением; пауза, `poster`,
  остановка вне вьюпорта — как сейчас.
- **Reduced motion.** Отключает переходы, reveal и заливку; интерфейс остаётся полным.

## 7. Компоненты

- **Кнопки.** Primary — `rounded-none`, жёлтая заливка, пиксельный hover. Secondary — pill, прозрачный
  фон, hairline-обводка. На экране один primary; secondary только если есть альтернативный путь.
  Одинаковая пара primary+secondary не повторяется на странице дважды.
- **Навигация.** Прозрачный слой без рамки и без «коробки»: `fixed` сверху, лёгкое размытие фона,
  ссылки обычным текстом по центру, активный пункт — жёлтая пилюля, CTA — pill-обводка. Никакой
  контейнер-таблетки вокруг всей шапки нет. Контент начинается ниже (`pt-24 sm:pt-28`).
- **Карточки.** Прямые углы, hairline-граница, без тени; hover — смена границы и фона, не масштаб.
- **Формы.** Тёмные поля, hairline-граница, подпись над полем, ошибка текстом; primary-кнопка одна.
- **Футер.** Три колонки, нейтральные ссылки, без повторного CTA-блока, если CTA уже был выше.

## 8. Постраничная композиция

| Маршрут | Роль страницы | Композиция | Геометрия |
| --- | --- | --- | --- |
| `/` | заявление студии | hero-манифест как в референсе, затем направления, история, услуги, блог, один CTA | точечное поле + мозаика слева снизу + решётка справа снизу |
| `/services` | выбор услуги | компактный заголовок с метриками (позиций, стартовая цена), два нумерованных реестра, сетка 3 колонки, одна кнопка на карточку | тихая полоса сетки сверху, 30 % прозрачности |
| `/shop` | товары | сетка карточек, пустое состояние с честным текстом | узкое поле справа |
| `/blog` | редакция | заголовок + фильтр + сетка статей | решётка окружностей в шапке |
| `/blog/[slug]` | чтение | одна колонка 68ch, обложка сверху, навигация поста | без декора |
| `/ai` | анонс направления | два агента, shader-видео, объяснение границ | плотная сетка сверху |
| `/ai/[agent]` | разбор агента | видео → сценарий → механизм → ограничения | без декора, видео — главный объект |
| `/contact` | заявка | форма + выбор услуг, шаги, итог | узкая колонка сетки слева |
| `/login`, `/signup` | вход | одна карточка по центру, без второго CTA | мозаика в углу |
| `/cart`, `/orders`, `/profile` | кабинет | таблицы и списки, действия по одной кнопке | без декора |
| `/privacy`, `/terms` | документ | колонка 72ch, только текст и hairline | без декора |
| `/payment/*` | результат | короткий статус + один следующий шаг | без декора |

Правило против шаблонности: hero-манифест существует **только** на главной; внутренние страницы
начинаются с компактного заголовка и сразу переходят к делу; одинаковый набор «eyebrow + заголовок +
описание + две кнопки» больше не тиражируется.

## 9. Что уже сделано в этой итерации

- точечная волна из курсора удалена; JS-контроллер `cursor-fill-controller` удалён из `Providers`;
- шапка стала плавающей pill-панелью, контент получил отступ под неё;
- primary-кнопка получила быструю пиксельную заливку (220 мс, `steps(6)`), только жёлтая шкала;
- пурпур убран из всех публичных компонентов и орнаментов (`tone="signal"` по умолчанию);
- hero приведён к логике референса: точечный фон, подсветка одного слова `.pip-mark`, короче подпись,
  больше воздуха, орнаменты только в нижней зоне и не пересекаются с текстом;
- правовые страницы очищены от декора;
- сетки стали тише (линии 0.05/0.09), полосы орнаментов — ниже и прозрачнее.

## 10. Этапы и приёмка

**P0 (сделано).** Анимация и цвет: пиксельная заливка, отсутствие пурпура, очистка правовых страниц.

**P1 (сделано).** Главная и шапка: hero приведён к референсу (точечное поле, подсветка слова, ритм),
навигация стала плавающей pill-панелью, дубли CTA убраны, первый экран читается без декора.

**P2 (идёт).** Готово: страница услуг — компактный заголовок с метриками, два нумерованных реестра,
сетка 3 колонки вместо тесной 4-колоночной, одна видимая кнопка на карточку (корзина стала тихим
текстовым контролом), микроподпись категории вместо бейджа, спокойная полоса сетки. Также убраны
повторяющиеся пары кнопок (`/shop`, `/contact`), правовые страницы очищены от декора.

Дальше: магазин и карточка товара по той же логике, единый компактный заголовок остальных внутренних
страниц, плотность таблиц кабинета.

**P3.** Проверка: клавиатура, reduced motion, RU/EN, длинные тексты, 320–1440 px, контраст жёлтого на
графите, отсутствие перекрытий декора и текста на каждом маршруте.

Критерии приёмки:

1. ни один текст и ни одна кнопка не пересекаются с декором и не «тонут» в сетке;
2. на экране не больше одного primary-действия и одного подсвеченного слова;
3. пурпур не встречается в публичном интерфейсе;
4. hover-движение занимает ≤250 мс и полностью выключается при reduced motion;
5. `npx tsc --noEmit`, `npx eslint .`, `npm test`, `npm run build` — зелёные.
